AI PROJECTS
- HireReady AI, an AI interview coach (in progress): you upload a job description and your resume, and get a realistic, role-tailored voice mock interview. Planned features: RAG-generated questions drawn from the JD and resume, a LangGraph agent that adapts its follow-up questions, LLM-based answer scoring, and a personalized study plan. Stack: React, TypeScript, Node.js, Python, FastAPI, LangGraph, OpenAI, a vector database, and MongoDB.
- QueryMind, talk to your database (in progress): you ask a question in plain English, and an agent writes the SQL or MongoDB query, runs it safely, and answers with a table or chart. Planned features: schema-aware text-to-query using RAG over database metadata, a LangGraph plan, check, and self-correct loop, read-only guardrails and row limits, and MCP connectors for PostgreSQL and MongoDB. Stack: React, TypeScript, Node.js, Python, FastAPI, LangGraph, MCP, PostgreSQL, MongoDB, and OpenAI.
- Multimodal RAG (GitHub: multimodal-rag): a pipeline for chatting with PDFs that contain text, tables, and charts/diagrams. I extract text and tables with PyMuPDF (tables kept as Markdown so rows and columns survive), use a vision LLM to write text summaries of images and charts, embed everything with one sentence-transformers model, and store it in a single Pinecone index with modality and page metadata. At query time, if any visual chunks come back, the question goes to a vision LLM along with the original image; otherwise a text LLM answers. Answers are grounded with page references. Built with LangChain, Pinecone, and Groq.
- BRD Builder AI: an AI-assisted platform for gathering, validating, and generating Business Requirements Documents. It does requirement gathering through conversational AI, context-aware gap detection, RAG-based retrieval and validation, and structured BRD generation, using LLMs, LangGraph, agentic workflows, embeddings, and MCP.
- DishGen AI (GitHub: dishgen-ai, live at dishgen-ai.netlify.app): a full-stack TypeScript "personal AI chef" that generates recipes from your cuisine, dietary preferences, and available ingredients, streaming results in real time. Built with React, Vite, Tailwind/shadcn, Node.js/Express, the OpenAI API, and Server-Sent Events.
